## 下单前值得确认的几个限制

**流量是双向计费。** 500GB、800GB、1200GB 都是上传加下载合计，不是单向额度。拿 500GB 当单向流量去规划视频或大文件下载，实际可用量会少一半。

**付款方式只有支付宝。** 国内用户方便，海外用户或者习惯 PayPal、信用卡的人会被卡住。

**系统只有 Linux。** CN2 GIA VPS 系列以 Linux 为主，不支持 Windows。需要 Windows 得看独立服务器产品线，或者换别家。

**入门档没有月付。** 想先花小钱试一个月的人买不到 299 这档，只能买季付 99 元，或者干脆用测试 IP 先测线路再决定。

**1000Mbps 是端口上限，不是保证跑满。** 512MB 内存加 10GB 硬盘的机器，跑满 1Gbps 不现实，端口给的是峰值空间。真要跑大带宽，配置得跟着上去。

买前自测线路的方法：圣何塞 `sjclg.akkocloud.com`，法兰克福 `fralg.akkocloud.com`，伦敦 `lonlg.akkocloud.com`，ping 一下、traceroute 一下，看自己运营商到机房的走线，比看任何测评都直接。
